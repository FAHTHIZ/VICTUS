# Ruin Runner (VICTUS sample)

A side-view 2D platformer built only from engine features. Run and jump through three levels of
grassy ruins: hop over spikes and gaps, stomp the beetles, use the wooden planks you can jump up
through, raise checkpoint flags and reach the golden banner at the end of each level.

```sh
victus run samples/platformer                 # play (A/D / arrows / left stick run, Space / W / A button jump, S drops, R restarts the level)
victus_editor samples/platformer              # open it in the editor
victus simulate samples/platformer --scene scenes/autoplay.vscene --frames 6000 --seed 1 --save final.vscene
```

`scenes/autoplay.vscene` is the same game with the hero's `autopilot` property on: it runs right
and jumps when its probes into the "Ground" and "Decor" tilemaps find a wall, a gap, spikes or a
beetle ahead. The `victus_sample_platformer` CTest runs it headless and checks that all three
levels are cleared; `victus_perf_budgets` checks its per-frame counters.

## Levels

Levels are plain text in `assets/scripts/levels.luau` (one string per row, top row first, 1 m
tiles): `#` ground, `=` one-way plank, `^` spikes, `o` coin, `E` beetle, `C` checkpoint, `G` goal,
`P` start, `*` bush. `game.luau` turns them into tilemaps and entities when a level starts;
restart the game to try an edited map. Keep jumps within reach: the hero clears walls two tiles high and gaps up to about five tiles.

## What it uses

| Engine feature | Where |
| --- | --- |
| Tile set with solid and one-way tiles | `assets/tilesets/ruins.vtileset` |
| Two `Tilemap` layers built at run time (`set_tile`, `clear_tiles`, `tile`, `world_to_tile`, `tile_to_world`) | `Ground` (merged Box2D colliders), `Decor` (spikes, flags, bushes) |
| Side-view `CharacterController2D` with gravity, jumping, one-way platforms (`drop_through`) and launch velocity (stomp bounce) | `Hero` + `assets/scripts/hero.luau` |
| Script modules (`require`) | `assets/scripts/levels.luau` |
| Pixel-art texture (`"filter": "nearest"`) cut into sprites with `uv`, sprite frame animation by UV swap | `assets/textures/ruin_tiles.png(.meta)` |
| Entities spawned from scripts (`scene.spawn`, `entity:set("Sprite", ...)`) | coins and beetles |
| Game UI (canvas, panels, text), input actions with gamepad bindings, audio | `HUD`, `victus.project` |

## Art

`assets/textures/ruin_tiles.png` is generated by `tools/generate_tiles.py` (Pillow) and is part of
this repository under the same licence; the two sounds come from the engine's 2D project
template. Tiles 0-3 are grass, earth, stone and plank; 4-7 spikes, checkpoint (down/up) and goal;
8-10 the hero's idle/run/jump frames; 11 a coin; 12-13 the beetle's walk frames; 14-15 decor.

# Dungeon Crawler (VICTUS sample)

A top-down 2D maze game built only from engine features, to show that VICTUS is not limited to
one genre. Every floor is generated at run time: walk the maze, collect every gem to open the
exit portal, avoid the slimes, and clear three floors that grow larger each time.

```sh
victus run samples/dungeon_crawler                 # play (WASD / arrows / left stick, Shift runs, R restarts the floor)
victus_editor samples/dungeon_crawler              # open it in the editor
victus simulate samples/dungeon_crawler --scene scenes/autoplay.vscene --frames 36000 --seed 1 --save final.vscene
```

`scenes/autoplay.vscene` is the same game with the hero's `autopilot` property on: it finds its
way with a breadth-first search over the wall tilemap and plays all three floors by itself. The
`victus_sample_dungeon_crawler` CTest runs it headless and checks that the dungeon is cleared.

## What it uses

| Engine feature | Where |
| --- | --- |
| Tile set with per-tile collision and a 16-tile wall terrain | `assets/tilesets/dungeon.vtileset` |
| Two `Tilemap` layers (floor without collision, autotiled walls with merged Box2D colliders) | `Floor`, `Walls` in `scenes/main.vscene` |
| Run-time level generation (`fill_tiles`, `set_tile`, `paint_terrain`, `clear_tiles`, `tile_to_world`, `world_to_tile`, `tile_bounds`) | `assets/scripts/dungeon.luau` |
| Top-down `CharacterController2D` (`top_down`) sliding along tile walls | `Hero` + `assets/scripts/hero.luau` |
| Pixel-art texture (`"filter": "nearest"`), sprites cut from the same texture with `uv`, pixel-snapped orthographic camera | `assets/textures/dungeon_tiles.png(.meta)`, `Main Camera` |
| Entities spawned and configured from scripts (`scene.spawn`, `entity:set("Sprite", ...)`) | gems and slimes |
| Game UI (canvas, panels, text) and input actions with gamepad bindings | `HUD`, `victus.project` |
| Seeded `math.random` for reproducible levels | `--seed` |

## Art

`assets/textures/dungeon_tiles.png` is generated by `tools/generate_tiles.py` (Pillow) and is
part of this repository under the same licence; the two sounds come from the engine's 2D
project template. Tiles 0-15 are the wall autotile (indexed by which of the north 1 / east 2 /
south 4 / west 8 neighbours are walls), 16-18 floors, 19/20 the closed/open exit, 21-23 floor
details and 24-26 the hero, gem and slime sprites.

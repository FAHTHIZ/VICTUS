# Competitor benchmark (Workstream F)

Dated: **2026-11-18**. Scope: `docs/handoff/COMPETITIVE_MATURITY_GAP_CLOSURE.md`, Workstream F.
VICTUS revision: `main` at `a61b143`.

This is a comparison by workflow. It uses primary documentation for the other engines and VICTUS's own recorded evidence (`docs/KNOWN_LIMITATIONS.md`, `docs/PLATFORM_SUPPORT.md`, `docs/STATUS.md`). There is **no overall score**: one number would hide the rows where VICTUS is far behind.

## Method and limits

- **Competitor versions (current stable on 2026-11-18):**
  - **Godot 4.7.2.** Released 2026-08-18 (<https://github.com/godotengine/godot/releases>, <https://godotengine.org/>). 4.8 is in beta (beta3 on 2026-11-09; <https://godotengine.org/download/archive/index.html>). Feature claims come from the 4.7 "List of features" page (<https://docs.godotengine.org/en/stable/about/list_of_features.html>).
  - **Unity 6.3 LTS (6000.3).** Shipped 2025-12-04 and supported until Dec 2027 (<https://unity.com/blog/unity-6-3-lts-is-now-available>, <https://unity.com/releases/unity-6/support>). 6000.6 is the current Supported update stream (<https://endoflife.date/unity>). Claims come from the 6.3 manual (<https://docs.unity.com/en-us/engine/6000.3/manual>), the platform page (<https://docs.unity.com/en-us/engine/6000.3/manual/platform-specific>) and the system requirements page (<https://docs.unity.com/en-us/engine/6000.3/manual/get-started/install-and-upgrade/getting-started-installing-unity/system-requirements>).
  - **Unreal Engine 5.8.** Announced 2026-06-23 as the last planned major UE5 release (<https://www.unrealengine.com/news/unreal-engine-5-8-is-now-available>). Hotfix 5.8.4 is the latest. Claims come from the 5.8 release notes (<https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-5-8-release-notes>), the hardware and software specifications (<https://dev.epicgames.com/documentation/unreal-engine/hardware-and-software-specifications-for-unreal-engine>), the mobile page (<https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-creating-mobile-games>) and the 5.7 release notes (<https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-5-7-release-notes>).
- **Cells marked "(UE docs)" or "(manual)" without a specific page** name well-known subsystems: Chaos, MetaSounds, UMG, StateTree, EQS, Unreal Insights, Fab, Interchange, Unity's audio mixer, Package Manager and AI Navigation. The specific pages for these were **not re-fetched for this revision**. Treat these cells as lower-confidence until a page is linked. The Unreal Quad Overdraw/Shader Complexity sources are already cited in `docs/RESEARCH_REGISTER.md` (overdraw entry).
- **No side-by-side measurements were run.** This machine has only a software rasteriser (lavapipe) and no competitor installs. Every row that depends on performance or usability is therefore at best "unknown/unmeasured" for VICTUS. Competitor feature claims come from vendor documentation and were not independently reproduced.
- **Other open-source engines are not compared here.** Examples are Bevy, O3DE, Defold and Stride. Their docs were not reviewed for this revision, and adding them without sources would weaken the table.
- **Classification labels**, as defined in the handoff: **verified competitive**, **competitive in a narrow area**, **behind**, **not yet implemented**, **unknown/unmeasured**.

## Highest-impact gaps (evidence-ordered)

1. **Real-hardware proof (rendering, performance, Android).** Every performance claim is unmeasured. Mobile is a primary target, yet the APK has never been installed. This is blocked on hardware (Workstream A) and must stay explicit until a device run is recorded. Engineering prep that does not need hardware, such as a device-run checklist and on-device stats overlay export, should be kept ready.
2. **Diagnostics: GPU timings, crash reports and a release process (Workstream D).** All three competitors document GPU-level profiling. VICTUS has none, and no crash bundle or release/tag process. The crash bundle and release process can be built and tested now, so they are the **next unblocked work**.
3. **Plugin SDK / versioned public API.** All three competitors are extensible through native plugins (GDExtension, packages, UE plugins). VICTUS has nothing. This needs an ADR (ABI and versioning) and a 60–90 minute foundation research block.
4. **Platform export breadth.** iOS, Web, consoles and D3D12 are missing, and Android is unverified. Web and iOS need their own ADRs. Consoles need platform-holder agreements, which is a business decision that must be escalated.
5. **Character animation depth.** IK, retargeting and layers/masks are missing; Godot documents IK and Unreal ships IK retargeting. This blocks credible 3D character games.

Editor UX (Workstreams B/C, Studio UX handoff) is also behind. It is ranked just below these because its most important evidence, usability with real users, cannot be measured here. Its Phase 0 audit is still scheduled.

## Roadmap ordering changes

- Workstream D (crash/diagnostics bundle, then release process) moves ahead of the optional Workstream H render items (hashed alpha, phone-wire AA, secondary-camera budget).
- The plugin SDK foundation research and ADR are added to the queue after D, before the 6c Studio UX Phase 0 audit.
- Animation depth (IK first, then layers/masks) is queued after the plugin SDK ADR.
- Hardware proof stays first in importance but remains **blocked**. It is not reordered away; it is reported as blocked.
